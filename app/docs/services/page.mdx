# Playlists and services

A **playlist** is the order of service: the music, in order, with text lines such as *Readings* or *Sermon* in between.

## Making one

1. **Playlists**, then **New playlist**. It suggests next Sunday's date.
2. **Add music** and tick pieces in the order you want them.
3. For each piece, choose what happens **Then**:
   - **Wait for Play**: it's ready, and starts when someone presses Play.
   - **Start by itself**: it starts after the pause you set (useful for a run of voluntaries).
   - **Cue at first note**: the stops are set and it waits at the first note, so Play starts the music instantly.
4. **Verses**: type `4` to play four verses, or a list like `1, 2, 5` to play exactly those. Leave it empty for all of them.
5. A **Note** shows beside the piece, for example *Hymn 477, page 312*.

Changes save themselves. **Repeat**, **Shuffle** and **Silent mode** (leave the stops drawn when a piece ends) are at the top.

## Running the service

Press **Run service** to open the **Service** screen: large text, the current piece highlighted, the next one marked, and big buttons. **Space** plays and pauses; the **right arrow** goes to the next piece. Tap any piece to make it the next one.

If a piece was edited after it was added to a playlist, it shows **Edited**, so nobody is surprised on Sunday. Saving the playlist clears the warning.
